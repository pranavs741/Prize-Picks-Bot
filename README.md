# NBA Player Performance Predictor

Author: Pranav Singh

# Project Description

This project focuses on predicting Stephen Curry's statistical performance in NBA games using machine learning. By analyzing Curry's historical game data, opponent matchups, and teammate availability, I aim to build predictive models that can forecast his key statistics such as points, assists, rebounds, and shooting percentages for upcoming games. 

---

# Installation Instructions

### Prerequisites
- Python 3.8 or higher
- pip package manager

### Setup
1. Clone this repository


2. Install required packages:
   ```bash
   pip install -r requirements.txt
   ```

3. Navigate to the main directory:
   ```bash
   cd main
   ```

4. Open the Jupyter notebook:
   ```bash
   jupyter notebook PointsPredictor.ipynb
   ```

# Data Access


### Generated Datasets
The following CSV files are generated by our preprocessing scripts:
- `curry_game_logs.csv` - Stephen Curry's game statistics (2013-2025)
- `opponent_matchup.csv` - Opponent team statistics for each game
- `teammate_availability.csv` - Tracks whether key teammates (Klay Thompson, Draymond Green, Kevin Durant) played

# Project Outline / Plan

## Data Collection Plan

The project utilizes three CSV datasets located in the `main/` folder:

1. **curry_game_logs.csv** - Contains Stephen Curry's detailed game-by-game statistics including points, assists, rebounds, field goals, three-pointers, free throws, steals, blocks, and other performance metrics across multiple seasons.

2. **opponent_matchup.csv** - Contains information about the opposing teams for each game, including their defensive statistics and team performance metrics that may impact Curry's performance.

3. **teammate_availability.csv** - Tracks the availability of key teammates (such as Klay Thompson, Draymond Green, and Kevin Durant) for each game, which can influence Curry's role and statistical output. 
 

## Model Plan

Curry's stats model: For the Curry model, we can potentially create a LSTM model where we can ask "Can we predict Stephen Curry's points in the next game?"

# Reproducibility

To reproduce our results:
1. Install dependencies from `requirements.txt`
2. Ensure all CSV data files are in the `main/` directory
3. Run the notebooks `PointsPredictor.ipynb` and `GamePredictor.ipynb` from top to bottom
4. The models use a fixed random seed (42) for reproducibility
